Mapeando Temática em Tokens

  • O Analisador Léxico não entende lógica, apenas agrupa caracteres.
  • Identidade Visual: Substituímos palavras comuns (`int`, `if`) pelo jargão da série (`PILOT`, `AT_FIELD`).
  • Expressões Regulares (Regex): Identificação dinâmica de números, identificadores e strings.
  • O Scanner gerado possui 164 estados DFA otimizados.

  "AT_FIELD"       { return symbol(sym.AT_FIELD); }
  "MISSION"        { return symbol(sym.MISSION); }

  "//"[^\r\n]* { /* discard single-line comments */ }

A Burocracia

Regras Gramaticais LALR

  • O Parser recebe os Tokens e verifica se a ordem faz sentido.
  • Construção de nós para Loops (`MISSION`), Condicionais (`AT_FIELD`) e Atribuições.
  • Ação Semântica: Integrada nas regras JCup. Utiliza Java para validar Tabela de Símbolos (Ex: proibir redeclaração do mesmo piloto).
/* Fragmento de nervlang.cup */
var_decl ::=
    PILOT type:t IDENTIFIER:vn ASSIGN expr SEMI
    {:
        // Ação Semântica em Java
        String scope = sa.getCurrentClass();
        sa.declareVar(vn, t, scope, 0, 0); // Valida Tabela

        System.out.println("[Lexical] Variable: " + t + " " + vn);
        System.out.println("[Semantic] Assigned type " + t);
    :} ;

stmt ::=
    | MISSION LPAREN for_init SEMI expr SEMI assignment RPAREN
      LBRACE stmt_list RBRACE
    {: System.out.println("[Syntactic] MISSION (for) -- OK"); :} ;

A Sintaxe NervLang

Como um programador escreve

  • Código estruturado dentro de classes `MAGI`.
  • Variáveis são `PILOT`, com tipos estritos (`INTEGER`, `BOOLEAN`).
  • If e Else se tornam verificação de escudo `AT_FIELD` e `ALTER`.
  • Print no terminal mapeado para `COMMUNICATE`.
/* Script de Calibração escrito em NervLang */
MAGI SyncTest {
    ORDER VOID main() {
        PILOT INTEGER sync_rate = 25;
        PILOT TEXT pilot_name = "Ikari Shinji";

        MISSION (PILOT INTEGER phase = 1; phase <= 3; phase++) {
            COMMUNICATE("Fase de calibracao:");
            COMMUNICATE(phase);
            sync_rate = sync_rate + 15;
        }

        AT_FIELD (sync_rate > 60) {
            COMMUNICATE("Status: PADRAO AZUL. Sincronizacao estavel.");
        } ALTER {
            COMMUNICATE("Status: PADRAO LARANJA. Risco de Berserk.");
        }
        SYNC;
    }
}

O Interpretador Tree-Walking

Dando Vida à AST

  • A maioria dos trabalhos acadêmicos para apenas na validação do texto.
  • A NervLang executa a Árvore Sintática na memória ram.
  • Calcula a matemática, resolve a precedência e gerencia escopo dinâmico de métodos.
  • Engenharia de precisão: Controle de blocos condicionais aninhados ignorando `ALTER` caso o `AT_FIELD` seja verdadeiro.
/* Controle Condicional no Interpretador */
else if (t == TT.AT_FIELD) { // if / if-else
    advance(); expect(TT.LPAREN);
    Object cond = evalExpr(); // Resolve a matemática
    expect(TT.RPAREN); expect(TT.LBRACE);

    if (toBool(cond)) {
        execBlock(); // Executa o Bloco
        if (peek().type == TT.ALTER) {
            advance(); expect(TT.LBRACE);
            skipBlock(); // IGNORA O ELSE
        }
    } else {
        skipBlock(); // IGNORA O IF
        if (peek().type == TT.ALTER) {
            advance(); expect(TT.LBRACE);
            execBlock(); // Executa o Else
        }
    }
}
